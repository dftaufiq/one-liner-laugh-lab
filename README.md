"One-Liner Laugh Lab" bounty, $2.50 in USDC.

> It was either the sock or the charging cable, and the cable fights back.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (1–200 UTF-8 characters, as the gate requires).
